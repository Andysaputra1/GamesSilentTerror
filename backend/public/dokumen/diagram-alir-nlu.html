Asumsi

A. Data dan label

  • Label intent dan target di dataset dianggap benar; teks identik berlabel ganda dibuang, duplikat persis disimpan sekali.
  • Test (20%) disisihkan sebelum pemilihan parameter dan hanya dipakai untuk pelaporan.
  • Dataset target adalah data pilot (775 pesan, 25 per kasus), jadi skor per kasus masih sangat bervariasi.
  • Anotasi konteks di dataset target adalah label benar; di game anotasi berasal dari prediksi sebelumnya, sehingga skor test adalah batas atas.
  • Pesan dari satu grup kalimat sumber tidak dipisah ke train dan test (dataset target), agar parafrase tidak bocor.

B. Model klasik

  • Chat direpresentasikan sebagai kantong kata/potongan karakter berbobot TF-IDF; urutan kata hilang di luar n-gram.
  • Naive Bayes menganggap fitur saling bebas bila kelas diketahui; SVM memisahkan kelas dengan batas linear.
  • Parameter dipilih dari rata-rata macro-F1 5-fold CV dengan fold yang sama untuk semua kandidat.

C. IndoBERT

  • Model pralatih indobenchmark/indobert-base-p1 di-fine-tune penuh; setiap learning rate mulai dari bobot pralatih dan seed yang sama.
  • Checkpoint dipilih dari macro-F1 validation; early stopping patience 3 dengan ambang kenaikan 0,001.
  • Confidence softmax belum dikalibrasi dan ketimpangan kelas tidak memakai loss berbobot.
  • Nama pemain disamarkan (target) atau divariasikan (intent di game) agar model belajar pola kalimat, bukan nama.

Cara hitung

Angka diambil dari artefak run yang sudah ada saat dokumen dibangun. Langkah yang ditandai "ilustrasi" memakai angka contoh untuk menjelaskan rumus.

1

Pembersihan dan distribusi data (intent)

baris bersih = baris mentah − kosong − duplikat persis − teks berlabel ganda

5.615 − 0 − 4 − 0 = 5.611 chat. Distribusi: defend 942 (16,8%), neutral 2.108 (37,6%), offend 2.561 (45,6%). Kelas defend paling sedikit, jadi macro-F1 dipakai sebagai metrik pemilihan.

2

Pembagian data

test = 20% (stratified); validation IndoBERT = 15% dari sisa; train = sisanya

Test 1.123 chat; sisa 4.488 → validation 15% = 842, train 3.646. Model klasik memakai seluruh 4.488 chat untuk 5-fold CV.

3

TF-IDF (fitur model klasik)

tf' = 1 + ln(tf) bila sublinear; idf(t) = ln((1 + n) ÷ (1 + df(t))) + 1; bobot = tf' × idf, lalu vektor tiap chat dinormalisasi L2 (panjang 1)

Ilustrasi: kata yang muncul 2 kali dalam satu chat dan ada di 50 dari 4.488 chat train: tf' = 1 + ln 2 = 1,693; idf = ln(4.489 ÷ 51) + 1 = 5,478; bobot = 9,274 sebelum normalisasi. Kata langka berbobot lebih besar daripada kata yang ada di hampir semua chat.

4

Pemilihan parameter: macro-F1 cross-validation

skor kandidat = rata-rata macro-F1 dari 5 fold; test tidak pernah dipakai memilih

SVM Grid Search mencoba 720 kombinasi → terbaik C = 2,0, n-gram (1, 2), analyzer word; macro-F1 CV = 0,830 ± 0,008. NB Grid Search (1.920 kombinasi): 0,809.

5

Penghentian Optuna

berhenti bila sudah ≥ 100 trial selesai dan 30 trial berturut-turut tanpa kenaikan ≥ 0,001, atau 500 trial

SVM Optuna berhenti di trial 130 (stagnation): 100 trial awal + 30 tanpa kenaikan berarti. Macro-F1 CV 0,830, hampir sama dengan Grid (0,830) dalam 160 detik vs 745 detik.

6

Softmax dan loss IndoBERT

pi = ezi ÷ Σj ezj; loss = −ln plabel benar

Ilustrasi logit z = (2,1, 0,4, -1,2) untuk (offend, neutral, defend): p = (0,820, 0,150, 0,030). Bila label benar offend, loss = −ln 0,820 = 0,198. Confidence yang dipakai game adalah p terbesar; chat dihitung sebagai bukti bila ≥ 0,60.

7

Jadwal learning rate

langkah per epoch = ⌈train ÷ batch efektif⌉; total = epoch maks × langkah; warmup = ⌈10% × total⌉; lr naik linear 0 → lrmaks selama warmup, lalu turun linear ke 0 di langkah terakhir

⌈3.646 ÷ 16⌉ = 228 langkah per epoch; total 12 × 228 = 2.736; warmup 274 langkah. Untuk lrmaks = 3×10⁻⁵: di langkah 228 lr = 3×10⁻⁵ × 228 ÷ 274 = 2,496×10⁻⁵; di langkah 456 lr = 3×10⁻⁵ × (2.736 − 456) ÷ (2.736 − 274) = 2,778×10⁻⁵.

8

Early stopping dan pemilihan learning rate

berhenti bila macro-F1 validation tidak naik ≥ 0,001 selama 3 evaluasi; pilih learning rate dan checkpoint dengan macro-F1 validation tertinggi

Macro-F1 validation terbaik: lr 1×10⁻⁵ → 0,8556 (epoch 5, dilatih 5); lr 2×10⁻⁵ → 0,8545 (epoch 4, dilatih 6); lr 3×10⁻⁵ → 0,8636 (epoch 5, dilatih 8). Terpilih lr 3×10⁻⁵: puncak di epoch 5 (langkah 1140 = checkpoint-1140), lalu 3 epoch tanpa kenaikan sehingga berhenti di epoch 8.

9

Metrik test Model 1 (intent)

accuracy = Σ diagonal ÷ n; precision = TP ÷ prediksi kelas itu; recall = TP ÷ data kelas itu; F1 = 2PR ÷ (P + R); macro-F1 = rata-rata F1 semua kelas

Accuracy = 1.020 ÷ 1.123 = 0,9083. defend: P = 149/174 = 0,856, R = 149/188 = 0,793, F1 = 0,823; neutral: P = 399/460 = 0,867, R = 399/422 = 0,945, F1 = 0,905; offend: P = 472/489 = 0,965, R = 472/513 = 0,920, F1 = 0,942. Macro-F1 = 0,890. Pembanding: SVM baseline 0,8405, Naive Bayes baseline 0,6783, SVM Grid 0,8406 (semua macro-F1 test).

10

Data pasangan Model 2 (target)

pasangan = Σpesan jumlah kandidat (roster ditambah pemain semu sampai minimal 6)

775 pesan (offend 321, defend 323, neutral 131; 31 kasus) dibagi train/validation/test 496/124/155 pesan → 2.977/745/931 pasangan (± 6,0 kandidat per pesan). Learning rate terbaik: 1×10⁻⁵ → 0,9460; 2×10⁻⁵ → 0,9544; 3×10⁻⁵ → 0,9487.

11

Metrik test Model 2 (target)

macro-F1 relasi = rata-rata F1 offend dan defend; exact match pesan = proporsi pesan yang daftar targetnya persis benar

Pasangan: accuracy 0,9699 (didominasi tidak_ada), F1 defend 0,910; F1 neutral 0,919; F1 offend 0,889; F1 tidak_ada 0,983. Macro-F1 relasi = (0,889 + 0,910) ÷ 2 = 0,900; F1 neutral 0,919. Per pesan: exact match 0,858, target precision 0,885, recall 0,920.

12

Aturan minimal satu target (ambang)

pesan offend/defend tanpa pasangan berelasi → kandidat dengan p(relasi intent) tertinggi dipakai bila ≥ ambang; selain itu target = tidak_diketahui. Pesan neutral boleh tanpa target.

Ambang IndoBERT = 0,5 (dipilih dari validation). Pada test exact match dengan dan tanpa ambang sama (0,858), jadi aturan ini jarang terpakai pada data pilot; di game aturan yang sama ada di NLUIndoBERT.target.
