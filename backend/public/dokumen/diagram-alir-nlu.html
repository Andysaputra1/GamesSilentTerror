Asumsi

A. Data dan label

  • Label intent dan target mengikuti aturan tertulis data/ATURAN_LABEL.md (relabel 26 Okt 2026) dan dianggap benar; teks identik berlabel ganda dibuang, duplikat persis disimpan sekali.
  • Satu chat hanya punya satu intent; kalimat campuran (membela + menuduh) berintent offend, dan relasi per pemain (siapa dibela, siapa dituduh) dicatat Model 2.
  • Test (20%) disisihkan sebelum pemilihan parameter dan hanya dipakai untuk pelaporan.
  • Data tambahan (100 chat intent dan 500 sesi target, dibuat 27 Okt 2026 mengikuti plan03) dan pesan sesi dari dataset target hanya masuk train; validation dan test tetap dari dataset asli, kecuali 20% sesi target tambahan yang dipakai sebagai uji tambahan terpisah.
  • Dataset target asli adalah data pilot (775 pesan, 25 per kasus), jadi skor per kasus masih sangat bervariasi.
  • Anotasi konteks di dataset target adalah label benar; di game anotasi berasal dari prediksi sebelumnya, sehingga skor test adalah batas atas.
  • Pesan dari satu grup kalimat sumber tidak dipisah ke train dan test (dataset target), agar parafrase tidak bocor.

B. Model klasik

  • Chat direpresentasikan sebagai kantong kata/potongan karakter berbobot TF-IDF; urutan kata hilang di luar n-gram.
  • Naive Bayes menganggap fitur saling bebas bila kelas diketahui; SVM memisahkan kelas dengan batas linear.
  • Parameter dipilih dari rata-rata macro-F1 5-fold CV dengan fold yang sama untuk semua kandidat.

C. IndoBERT

  • Model pralatih indobenchmark/indobert-base-p1 di-fine-tune penuh; setiap learning rate mulai dari bobot pralatih dan seed yang sama.
  • Checkpoint dipilih dari macro-F1 validation; early stopping patience 3 dengan ambang kenaikan 0,001.
  • Confidence softmax belum dikalibrasi dan ketimpangan kelas tidak memakai loss berbobot.
  • Nama pemain disamarkan (target) atau divariasikan (intent di game) agar model belajar pola kalimat, bukan nama.

Cara hitung

Angka diambil dari artefak run yang sudah ada saat dokumen dibangun. Langkah yang ditandai "ilustrasi" memakai angka contoh untuk menjelaskan rumus.

1

Relabel dataset (26 Oktober 2026)

label baru = aturan tertulis ATURAN_LABEL.md diterapkan ke setiap chat; urutan keputusan offend → defend → neutral; kalimat campuran (membela + menuduh) = offend

Dataset intent: 331 dari 5.615 chat berubah (neutral→defend 183, defend→offend 84, offend→neutral 30, neutral→offend 23, offend→defend 9, defend→neutral 2). Dataset target: 262 pesan berubah intent atau targetnya, 2 di antaranya pesan utama; sisanya pesan konteks. Setiap perubahan tercatat di data/relabel_2026-10-26.csv.

2

Pembersihan dan distribusi data (intent)

baris bersih = baris mentah − kosong − duplikat persis − teks berlabel ganda

5.615 − 0 − 4 − 0 = 5.611 chat. Distribusi: defend 1.048 (18,7%), neutral 1.934 (34,5%), offend 2.629 (46,9%). Kelas defend paling sedikit, jadi macro-F1 dipakai sebagai metrik pemilihan.

3

Pembagian data

test = 20% (stratified); validation IndoBERT = 15% dari seluruh data; train IndoBERT = sisanya + chat tambahan + pesan sesi (teks yang ada di validation/test dibuang)

Test 1.123 chat; validation 15% × 5.611 = 842; sisa 8.623 + 100 chat tambahan + 4.877 pesan sesi dari sesi train dataset target = train 8.623. Validation dan test tetap dari dataset_final3.csv saja. Model klasik memakai seluruh 9.465 chat untuk 5-fold CV.

4

TF-IDF (fitur model klasik)

tf' = 1 + ln(tf) bila sublinear; idf(t) = ln((1 + n) ÷ (1 + df(t))) + 1; bobot = tf' × idf, lalu vektor tiap chat dinormalisasi L2 (panjang 1)

Ilustrasi: kata yang muncul 2 kali dalam satu chat dan ada di 50 dari 9.465 chat train: tf' = 1 + ln 2 = 1,693; idf = ln(9.466 ÷ 51) + 1 = 6,224; bobot = 10,538 sebelum normalisasi. Kata langka berbobot lebih besar daripada kata yang ada di hampir semua chat.

5

Pemilihan parameter: macro-F1 cross-validation (SVM/NB, run 25 Sep, label lama)

skor kandidat = rata-rata macro-F1 dari 5 fold; test tidak pernah dipakai memilih

SVM Grid Search mencoba 720 kombinasi → terbaik C = 2,0, n-gram (1, 2), analyzer word; macro-F1 CV = 0,830 ± 0,008. NB Grid Search (1.920 kombinasi): 0,809.

6

Penghentian Optuna (run 25 Sep, label lama)

berhenti bila sudah ≥ 100 trial selesai dan 30 trial berturut-turut tanpa kenaikan ≥ 0,001, atau 500 trial

SVM Optuna berhenti di trial 130 (stagnation): 100 trial awal + 30 tanpa kenaikan berarti. Macro-F1 CV 0,830, hampir sama dengan Grid (0,830) dalam 160 detik vs 745 detik.

7

Softmax dan loss IndoBERT

pi = ezi ÷ Σj ezj; loss = −ln plabel benar

Ilustrasi logit z = (2,1, 0,4, -1,2) untuk (offend, neutral, defend): p = (0,820, 0,150, 0,030). Bila label benar offend, loss = −ln 0,820 = 0,198. Confidence yang dipakai game adalah p terbesar; chat dihitung sebagai bukti bila ≥ 0,60.

8

Jadwal learning rate

langkah per epoch = ⌈train ÷ batch efektif⌉; total = epoch maks × langkah; warmup = ⌈10% × total⌉; lr naik linear 0 → lrmaks selama warmup, lalu turun linear ke 0 di langkah terakhir

⌈8.623 ÷ 16⌉ = 539 langkah per epoch; total 12 × 539 = 6.468; warmup 647 langkah. Untuk lrmaks = 3×10⁻⁵: di langkah 539 lr = 3×10⁻⁵ × 539 ÷ 647 = 2,499×10⁻⁵; di langkah 1078 lr = 3×10⁻⁵ × (6.468 − 1078) ÷ (6.468 − 647) = 2,778×10⁻⁵.

9

Early stopping dan pemilihan learning rate

berhenti bila macro-F1 validation tidak naik ≥ 0,001 selama 3 evaluasi; pilih learning rate dan checkpoint dengan macro-F1 validation tertinggi

Macro-F1 validation terbaik: lr 1×10⁻⁵ → 0,9156 (epoch 3, dilatih 6); lr 2×10⁻⁵ → 0,9112 (epoch 9, dilatih 12); lr 3×10⁻⁵ → 0,9247 (epoch 8, dilatih 11). Terpilih lr 3×10⁻⁵: puncak di epoch 8 (langkah 4312 = checkpoint-4312), lalu 3 epoch tanpa kenaikan sehingga berhenti di epoch 11.

10

Metrik test Model 1 (intent)

accuracy = Σ diagonal ÷ n; precision = TP ÷ prediksi kelas itu; recall = TP ÷ data kelas itu; F1 = 2PR ÷ (P + R); macro-F1 = rata-rata F1 semua kelas

Accuracy = 1.032 ÷ 1.123 = 0,9190. defend: P = 175/198 = 0,884, R = 175/210 = 0,833, F1 = 0,858; neutral: P = 359/401 = 0,895, R = 359/387 = 0,928, F1 = 0,911; offend: P = 498/524 = 0,950, R = 498/526 = 0,947, F1 = 0,949. Macro-F1 = 0,906. Karena label berubah, isi test ikut berubah, jadi angka ini tidak bisa dibandingkan langsung dengan run 25 Sep. Perbandingan adil dengan model lama yang dipakai game sampai 27 Oktober (run 25 Sep; sejak 27 Oktober game memakai model ini), pada data yang tidak pernah dilatih kedua model dan dinilai dengan label baru: Chat intent biasa (n=285): lama 0,888 / 0,857, baru 0,923 / 0,909 (recall defend 0,761 → 0,891); Pesan sesi, kondisi game (n=152): lama 0,638 / 0,640, baru 0,947 / 0,944 (recall defend 0,418 → 0,940) (accuracy / macro-F1). Pesan sesi dibuat dengan cara yang sama seperti pesan sesi di train, jadi kenaikannya pada chat pemain sungguhan kemungkinan lebih kecil. Hasil SVM/NB terakhir masih dari label lama: SVM baseline 0,8405, Naive Bayes baseline 0,6783, SVM Grid 0,8406 (macro-F1 test lama).

11

Data pasangan Model 2 (target)

pasangan = Σpesan jumlah kandidat (roster ditambah pemain semu sampai minimal 6)

775 pesan pilot (offend 322, defend 323, neutral 130; 31 kasus) dibagi train/validation/test 496/124/155 pesan; 400 sesi tambahan ikut train dan 100 sesi menjadi uji tambahan → train/validation/test/uji tambahan 5.377/745/931/600 pasangan (± 6,0 kandidat per pesan). Learning rate terbaik: 1×10⁻⁵ → 0,9457; 2×10⁻⁵ → 0,9513; 3×10⁻⁵ → 0,9527.

12

Metrik test Model 2 (target)

macro-F1 relasi = rata-rata F1 offend dan defend; exact match pesan = proporsi pesan yang daftar targetnya persis benar

Pasangan: accuracy 0,9817 (didominasi tidak_ada), F1 defend 0,957; F1 neutral 0,950; F1 offend 0,923; F1 tidak_ada 0,989. Macro-F1 relasi = (0,923 + 0,957) ÷ 2 = 0,940; F1 neutral 0,950. Per pesan: exact match 0,903, target precision 0,959, recall 0,927. Uji tambahan (100 sesi kasus sulit yang tidak dilatih): exact match 0,890. Perbandingan dengan model target lama yang dipakai game sampai 27 Oktober (run 16 Okt), dihitung lewat kode NLU game pada test yang sama dengan label baru: intent benar (label): exact match lama 0,852 → baru 0,903, precision 0,891 → 0,952, recall 0,921 → 0,927; kondisi game (intent ditebak): exact match lama 0,542 → baru 0,858, precision 0,594 → 0,890, recall 0,563 → 0,854. Pada kondisi game, model lama memakai intent 25 Sep dan model baru memakai intent 27 Okt, jadi sebagian besar kenaikan berasal dari Model 1. Recall offend turun (0,950 → 0,900; 3 dari 60 target) karena model baru lebih hati-hati menunjuk nama: salah tuduh turun dari 9 menjadi 4.

13

Aturan minimal satu target (ambang)

pesan offend/defend tanpa pasangan berelasi → kandidat dengan p(relasi intent) tertinggi dipakai bila ≥ ambang; selain itu target = tidak_diketahui. Pesan neutral boleh tanpa target.

Ambang IndoBERT = 0,5 (dipilih dari validation). Pada test exact match dengan dan tanpa ambang sama (0,903), jadi aturan ini jarang terpakai pada data pilot; di game aturan yang sama ada di NLUIndoBERT.target.
